FORTEAI — РАЗВЁРТЫВАНИЕ ТЕКУЩЕЙ ВЕРСИИ

1. Установите зависимости и веса по корневому README.md.
2. Для локального запуска используйте cash_ml.api:app и cash_ml/app.py.
3. Для собственного сервера скопируйте deploy/site.env.example в deploy/site.env.
   Укажите домен, новый случайный API_KEY, UI_USER и хеш пароля Caddy.
   Пароль можно хешировать интерактивно командой caddy hash-password.
4. Настройте DNS домена на сервер и разрешите входящие 80/443.
5. Из корня проекта выполните:
   docker compose --env-file deploy/site.env -f deploy/compose.yaml up --build -d

Модель анализирует видео локально. Внутренняя сеть контейнеров отделена от
внешнего шлюза. API защищается X-API-Key, UI — отдельной Basic Auth шлюза.
Не публикуйте .env, site.env, storage/ или приватные результаты.

Docker-конфигурация требует проверки на целевом сервере. Репозиторий и Release
сами по себе не создают публичный сайт и не гарантируют готовность к эксплуатации.
Собственные домен, сервер и политика хранения результатов задаются владельцем.

temporary_public.py и TEMPORARY_DEMO.txt содержат отдельный вариант временного
демо через локальный туннель. Текущий адрес указан в разделе README для жюри;
учётные данные не публикуются.

Текущая модель: typed_v2. Исходные видео и Excel не нужны для инференса.
Большие веса находятся в Release v1.0.1. После установки выполните
python scripts/verify_model.py. Сведения о сторонних лицензиях: third_party/.
