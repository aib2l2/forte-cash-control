# cash_ml — текущая версия ForteAI

Запуск и установка модели описаны в [основном README](../README.md).

Активная цепочка: `api.py` → `runtime.py` → `service.py` → `features.py`.
Интерфейс: `app.py`, `forte_ui.py`, `assets/`. Нормативные справки: `rules.py`
и `rule_registry.json`. Реальные доказательные кадры: `evidence.py`.

Подключена только `typed_v2`: замороженная R3D-18 и два линейных классификатора.
`train.py` содержит исходную процедуру обучения. Она перезаписывает активные
артефакты — для новых исследований используйте отдельную копию проекта.

Утилиты context/dense/temporal/description и локального просмотра сохранены
как код исследований. Их веса, приватная разметка, кэши и результаты не входят
в публикацию. Они не меняют активную модель автоматически.

Словарь состоит исключительно из 11 значений, зафиксированных в отчёте модели.
Все ограничения оценки качества указаны в основном README и отчёте обучения.
