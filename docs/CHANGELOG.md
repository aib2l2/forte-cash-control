# Изменения выпусков

## 1.0.1 — 18.10.2026

- Основные и совместимые точки запуска используют один сервис typed_v2.
- Убраны сообщения старого каркаса о неподключённой модели.
- При отсутствии файлов модели сервис предлагает установить веса из Release.
- README содержит публичные инструкции установки и раздел доступа для жюри.
- Кнопка презентации ведёт к актуальным инструкциям демо в GitHub.
- Нормативная документация указывает на действующий реестр.
- Обновлены метаданные приложения и проверки совместимых точек запуска.

Веса, классификаторы, пороги и словарь типов не менялись. Этот выпуск не является
новым обучением и не заявляет улучшения точности.

## 1.0.0 — архивный выпуск

Первоначальная публикация сервиса и весов. Архив исходников содержит прежний
README с инструкциями для приватного доступа. Для установки используйте 1.0.1
или актуальную ветку main.
