# Нормативный справочник текущей версии

Сервис использует [cash_ml/rule_registry.json](../cash_ml/rule_registry.json).
Проверка справочника и формирование пояснений находятся в
[cash_ml/rules.py](../cash_ml/rules.py). API возвращает его через
`GET /api/v1/rules` с заголовком `X-API-Key`.

[Снимки публичных источников](../outputs/case_review/legal_sources/) включены
в репозиторий. Применимость нормы и наблюдаемые действия проверяет оператор.
Для категорий без прямого подтверждённого основания справочник явно указывает
ограничение. Пустой файл старого каркаса больше не используется и удалён.
