# Проверенные правила

`rules.json` намеренно пуст: нормативные основания ещё не исследованы.
Добавляйте только проверенные публичные источники РК.

Для каждого элемента массива `rules` используйте поля:

| Поле | Содержание |
| --- | --- |
| `id` | Стабильный идентификатор правила |
| `event_type` | Тип из вашей разметки |
| `document` | Название документа |
| `section` | Пункт или раздел, если удалось установить |
| `url` | Прямая ссылка на источник |
| `requirement` | Смысл требования |
| `observable_signs` | Признаки, которые действительно можно увидеть |
| `limitations` | Что невозможно установить по видео |
| `verified_on` | Дата проверки источника |

Не объявляйте передачу денег или появление человека нарушением без контекста.
В API название документа, пункт и краткое обоснование включайте в `description`.
Не используйте шаблонные названия документов как настоящие нормативные ссылки.
